# Public 资源目录

请将以下资源文件放到对应目录：

## 图标文件

```
public/image/icon/
├── vista_messenger.jpg  # 头像/首页图标
├── vista_book_1.jpg     # 归档图标
├── vista_pc_1.jpg       # 关于图标
├── github.png           # GitHub 图标
└── bilibili.png         # Bilibili 图标
```

## 背景和封面

```
public/image/
├── bg.jpg              # 网站背景图片
└── cover.jpg           # 文章封面示例
```

## 音乐文件

```
public/music/
└── song.mp3            # 音乐文件
```

## 注意事项

1. 图标建议尺寸：24x24px 或 32x32px
2. 背景图片建议尺寸：1920x1080px 或更高
3. 封面图片建议尺寸：800x450px
4. 音乐文件支持 mp3 格式

你可以从原 Hexo 主题的 source 目录中复制这些文件。
